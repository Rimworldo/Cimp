Como usar o StreamCanvas (Convidados)

Visão geral

O Host cria uma sala e compartilha o código. Convidados entram, adicionam elementos que aparecem em tempo real na tela do Host — ideal para overlays de live.

Barra lateral

  • Imagem / GIF / Vídeo / Áudio / YouTube / Texto / HTML — escolha o conteúdo e clique na tela para posicionar.
  • Animar — selecione itens e abra o editor (Pulsar, Rodar, Mover, Orbitar).
  • Pincel / Borracha — desenhe livremente.

Seleção e grupos

  • Clique para selecionar. Ctrl/Cmd + clique adiciona à seleção.
  • Shift + arraste para selecionar vários (marquee).
  • Com 2+ itens selecionados, arraste um: todos se movem juntos.
  • Ctrl+G agrupa, Ctrl+Shift+G desagrupa, Ctrl+A seleciona todos.

Atalhos

  • Delete remove o(s) selecionado(s).
  • Ctrl+C / Ctrl+V / Ctrl+X copiar, colar, recortar.
  • Ctrl+Z / Ctrl+Y desfazer / refazer.
  • Esc cancela ferramenta.
