Como usar o StreamCanvas (Convidados)

Visão geral

O Host cria uma sala e compartilha o código. Convidados entram, adicionam elementos (imagens, vídeos, textos) que aparecem em tempo real na tela do Host — ideal para overlays de live.

Barra lateral (Toolbar)

  • Imagem / GIF / Vídeo / Áudio / YouTube / Texto / HTML — escolha o conteúdo e clique na tela para posicionar. Vídeos têm controles de play/pause, posição e volume no próprio player.
  • Animar — selecione um ou mais itens e abra o editor de animações (Pulsar, Rodar, Mover, Orbitar).
  • Pincel / Borracha — desenhe livremente na tela.
  • Tutorial — este guia.

Seleção e grupos

  • Clique em um item para selecionar. Ctrl/Cmd + clique adiciona à seleção.
  • Shift + arraste no fundo para selecionar vários de uma vez (marquee).
  • Com 2+ itens selecionados, arraste qualquer um deles: todos se movem juntos como uma entidade única.
  • Use a barra inferior: Agrupar, Desagrupar, Animar, Remover.
  • Itens agrupados ficam juntos: clicar em qualquer um seleciona o grupo inteiro. Arrastar, rotacionar e redimensionar age no grupo.
  • Botão direito em um item abre as opções dele (opacidade, vídeo/áudio, animação…). Em textos: botão direito no meio do texto edita, nas bordas abre as opções.
  • A barra inferior tem o controle de Opacidade: ele muda todos os itens selecionados de uma vez.
  • Atalho: Ctrl+G agrupa, Ctrl+Shift+G desagrupa, Ctrl+A seleciona todos os seus itens.

Animações

  • Pulsar — cresce e diminui. Ajuste velocidade e quanto cresce.
  • Rodar — gira continuamente. Ajuste velocidade e direção.
  • Mover — arraste os pontos A (início) e B (fim) no canvas. Escolha duração, modo (ida e volta / loop / uma vez) e suavização. Ao selecionar vários itens, todos mantêm o espaçamento relativo durante o movimento.
  • Orbitar — gira em volta de um centro. Arraste o ponto C para definir o centro; ajuste raio e velocidade.
  • Pré-visualização ao vivo enquanto edita. Clique Aplicar para salvar ou Remover para tirar a animação.

Handles nos itens

  • Verde (canto) — arrastar o item (ou todo o grupo selecionado).
  • Azul (topo) — rotacionar (grupos giram em torno do centro do grupo).
  • Cantos de resize — redimensionar.
  • Vermelho (X) — apagar.

Atalhos

  • Delete / Backspace — remove o(s) selecionado(s).
  • Ctrl+C / Ctrl+V — copiar e colar seus itens.
  • Ctrl+Z / Ctrl+Y — desfazer / refazer.
  • Esc — cancela ferramenta / fecha editor de animação.

Dicas para convidados

  • Só você edita os itens que criou. O Host vê tudo em tempo real (modo transparente para OBS).
  • Prefira agrupar elementos que devem se mover juntos (ex.: logo + texto).
  • Use Mover com ida-e-volta para banners que deslizam na tela.

Programar

Escolha um slot. Você entra em modo edição e só os elementos que você adicionar entram no preset. Ao sair, tudo é salvo. Depois use as teclas 1-0 para mostrar ou esconder o conjunto.
